# builds/

Finished tools go here, one folder per tool, each with a single `index.html` (see ADR-002).

`trip-cost-calculator/` is a finished example. Open its `index.html` in a browser to try it, and see `examples/trip-cost-calculator/` for the SPEC, TAD, and TASKS it was built from.

```
builds/
  lab-safety-quiz/
    index.html
```

Once GitHub Pages is on, each tool is live at `https://<username>.github.io/<repo>/builds/<tool-name>/`.
