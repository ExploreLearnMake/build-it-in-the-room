# Skills

A skill is a short Markdown file that teaches the AI something about *your* environment: how your LMS handles embedded content, your institution's color palette, the approved place to host a tool. The AI reads these when the TAD says the tool will live there.

Write one when you notice yourself explaining the same platform detail to the AI twice.

## Format

- **When to use this skill:** one sentence.
- **What to know:** the facts and constraints, as a short list.
- **Checklist:** what the AI must verify before calling the build done.

See `embed.md` for an example.
